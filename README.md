# 资源独占交接与输出提交缓存

把设备使用权从一个协作方交给另一个协作方时，凭证必须晚于本地句柄真正关闭。这个独立离线参考项目用假句柄演示状态机，并用单字节假输出演示“整包提交后才更新缓存”。

这是本次方法整理新写的参考实现，不是历史生产源码。只使用 Python 标准库、合成输入及假设备，没有 SDK、协议、硬件连接或设备操作。

## 运行

Python 3.10 或更新版本，在本仓目录运行：

```text
python demo.py
python -m unittest discover -s tests -v
```

演示输出应先显示 `LENT` 且本地句柄关闭，归还后显示 `LOCAL` 且恢复运行；假输出为 `10100001`，高位保持。

## 方法与取舍

- `ResourceHost` 保存原先打开/采集状态，按停止、关闭、授予、借方关闭、恢复的顺序交接。关闭失败不能授予；借方未关闭不能恢复。
- 凭证绑定随机会话和期限。过期凭证拒绝；显式回收仍要求借方句柄关闭。会话重建使旧凭证失效。
- `OutputCache` 初始为未知。只有明确观察后才能保留无关位；待提交期间禁止第二次修改；短写或异常使缓存重新未知。

详细规则见 [METHODS.md](METHODS.md)。

## 验证边界与许可

测试覆盖软件状态、过期/旧凭证、关闭与恢复失败、短写及位保持。内存替身不能证明跨进程强制排他、借方崩溃后硬件已释放、物理输出已改变或整机验收。真实集成还需要操作系统互斥、进程身份核查和设备回读。
